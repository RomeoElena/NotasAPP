# Aplicación de Notas

Es un proyecto sencillo de una aplicación web que permite a los usuarios gestionar notas de forma rápida y sencilla. El objetivo principal es poner en práctica la manipulación del DOM y la gestión de eventos con JavaScript.

## Requisitos del Proyecto:

La aplicación cumple con los siguientes puntos:
* **HTML:** 
Estructura con campo de texto, botón de acción y lista dinámica.
* **CSS:** 
Diseño limpio, responsive y con estilos diferenciados para botones y elementos de lista.
* **JavaScript:** 
Función para añadir notas al hacer clic o presionar **Enter**.
Función para eliminar notas específicas.
Limpieza del input tras cada inserción.

## Tecnologías Utilizadas:
* HTML5
* CSS3 
* JavaScript
